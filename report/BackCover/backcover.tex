\rule{\textwidth}{1pt}\\[0.3cm]
\textbf{Abstract}\\[0.25cm]
{\bcbodysize
Mid-sized DACH enterprises manage contracts by hand: deadlines pass unnoticed,
approvals leave no auditable record, and GoBD, GDPR and ISO~27001 demand
immutable records. \textbf{CLMPilot} is an integration-first CLM platform for
the DACH \textit{Mittelstand}: it owns metadata, deadlines, approvals and audit
trail; the document stays in the customer's storage.
Built on \texttt{comby}, an in-house Go CQRS and Event~Sourcing framework, its
audit trail is architectural.
\\[0.25cm]
\textbf{Keywords:} Contract Lifecycle Management, CQRS, Event Sourcing,
Audit Trail.\par}

%------------------------------------------------------------------- FRENCH ---
\rule{\textwidth}{1pt}\\[0.3cm]
\textbf{Résumé}\\[0.25cm]
{\bcbodysize
Les moyennes entreprises du DACH gèrent leurs contrats à la main : les échéances
passent inaperçues, les validations ne laissent nulle trace, quand le GoBD, le
RGPD et l'ISO~27001 imposent l'immuabilité. \textbf{CLMPilot} est
une plateforme CLM orientée intégration pour le \textit{Mittelstand} : elle
gère métadonnées, échéances, validations et audit ; le document reste chez le
client. Bâtie sur \texttt{comby}, framework Go interne CQRS/\textit{Event
Sourcing}, l'audit est architectural.
\\[0.25cm]
\textbf{Mots-clés :} gestion du cycle de vie des contrats, CQRS, Event
Sourcing, piste d'audit.\par}
