# PFE Notes — Tips, Recommendations & Rules

A topic-organized reference distilled from:

1. **The INSAT PFE LaTeX template** (the `_Modele PFE old FR` / `_ModelNewEN`
   source files — included sample chapters and appendix).
2. **`Pour Écrire un Bon Rapport.pdf`** (Lilia Sfaxi, December 2013) — the
   original guide from which the template's tips were extracted, fetched from
   the Drive folder. Contains a few rules the template appendix doesn't carry
   (title rule, sequence-diagram "no System/Database" constraint, typography
   baseline, figure source citation, etc.).
3. **`Sources` Google Doc** — the user's collected CQRS / Event Sourcing links,
   summarized in [tech-references.md](tech-references.md).
4. **`PFE examples/` folder** — seven sample PFE reports, indexed in
   [example-reports.md](example-reports.md).

Drive folder:
[PFE ressources](https://drive.google.com/drive/folders/1VdcQUBlagHLlIdyzCt_Bn6aa7dbyNcxc).
